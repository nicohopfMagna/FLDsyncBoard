# FLD-SyncBoard (Italiano)

## Panoramica
FLD-SyncBoard e una web app Node.js per dati principali, modelli turno, piani turno e simulazione API.

## Avvio
```bash
npm install
npm start
```
Apri: http://localhost:3000

## Funzionalita
- Cambio lingua in tempo reale
- Cambio tema scuro/chiaro
- Integrazione con SQL Server e MQTT
- Flussi di import/export e assegnazioni

## Risoluzione problemi
- Se il testo non cambia, fai refresh forzato del browser.
- Se l'avvio fallisce, esegui `npm start` e controlla gli errori nel terminale.
