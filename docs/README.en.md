# FLD-SyncBoard (English)

## Overview
FLD-SyncBoard is a Node.js web app for master data, shift models, shift schedules, and API simulation.

## Start
```bash
npm install
npm start
```
Open http://localhost:3000

## Features
- Runtime language switching
- Dark/light theme switch
- SQL Server and MQTT integration
- Import/export and assignment workflows

## Troubleshooting
- If UI text does not update, hard-refresh the browser.
- If startup fails, run `npm start` and check terminal errors.
