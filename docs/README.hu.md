# FLD-SyncBoard (Magyar)

## Attekintes
A FLD-SyncBoard egy Node.js webalkalmazas torzsadatokhoz, muszakmodellekhez, muszakbeosztasokhoz es API szimulaciohoz.

## Inditas
```bash
npm install
npm start
```
Megnyitas: http://localhost:3000

## Funkciok
- Nyelvvaltas futas kozben
- Sotet/vilagos tema valtas
- SQL Server es MQTT integracio
- Import/export es hozzarendelesi folyamatok

## Hibakereses
- Ha a szovegek nem frissulnek, vegezz hard refresh-t a bongeszoben.
- Ha az inditas hibas, futtasd a `npm start` parancsot es ellenorizd a terminalt.
