# FLD-SyncBoard (Chinese)

## 概述
FLD-SyncBoard 是一个 Node.js Web 应用，用于主数据、班次模型、班次计划和 API 模拟。

## 启动
```bash
npm install
npm start
```
打开: http://localhost:3000

## 功能
- 运行时语言切换
- 深色/浅色主题切换
- SQL Server 与 MQTT 集成
- 导入/导出与分配流程

## 故障排查
- 如果文本未更新，请强制刷新浏览器。
- 如果启动失败，请运行 `npm start` 并查看终端错误。
