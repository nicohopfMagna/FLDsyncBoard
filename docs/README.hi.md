# FLD-SyncBoard (Hindi)

## सारांश
FLD-SyncBoard एक Node.js वेब ऐप है, जो मास्टर डेटा, शिफ्ट मॉडल, शिफ्ट शेड्यूल और API सिमुलेशन के लिए है।

## शुरू करें
```bash
npm install
npm start
```
खोलें: http://localhost:3000

## फीचर्स
- रनटाइम भाषा स्विच
- डार्क/लाइट थीम स्विच
- SQL Server और MQTT इंटीग्रेशन
- इम्पोर्ट/एक्सपोर्ट और असाइनमेंट फ्लो

## समस्या निवारण
- यदि टेक्स्ट अपडेट नहीं होता, ब्राउज़र हार्ड रिफ्रेश करें।
- यदि स्टार्टअप फेल हो, `npm start` चलाएँ और टर्मिनल एरर देखें।
