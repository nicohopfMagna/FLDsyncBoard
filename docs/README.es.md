# FLD-SyncBoard (Espanol)

## Resumen
FLD-SyncBoard es una aplicacion web Node.js para datos maestros, modelos de turno, horarios y simulacion de API.

## Inicio
```bash
npm install
npm start
```
Abrir: http://localhost:3000

## Funciones
- Cambio de idioma en tiempo real
- Cambio de tema oscuro/claro
- Integracion con SQL Server y MQTT
- Flujos de importacion/exportacion y asignaciones

## Solucion de problemas
- Si los textos no cambian, recarga forzada del navegador.
- Si falla el arranque, ejecuta `npm start` y revisa errores en terminal.
