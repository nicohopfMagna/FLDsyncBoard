# FLD-SyncBoard (Slovensky)

## Prehlad
FLD-SyncBoard je Node.js web aplikacia pre hlavne udaje, modely zmien, plany zmien a API simulator.

## Spustenie
```bash
npm install
npm start
```
Otvor: http://localhost:3000

## Funkcie
- Prepinanie jazyka za behu
- Prepinac tmavej/svetlej temy
- Integracia SQL Server a MQTT
- Import/export a priradenia

## Riesenie problemov
- Ak sa texty nemenia, vykonaj tvrdy refresh prehliadaca.
- Ak start zlyha, spusti `npm start` a skontroluj terminal.
