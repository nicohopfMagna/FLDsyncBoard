# FLD-SyncBoard (Portugues)

## Visao geral
FLD-SyncBoard e um app web Node.js para dados mestres, modelos de turno, agendas e simulacao de API.

## Inicio
```bash
npm install
npm start
```
Abrir: http://localhost:3000

## Recursos
- Troca de idioma em tempo real
- Alternancia tema claro/escuro
- Integracao com SQL Server e MQTT
- Fluxos de importacao/exportacao e atribuicoes

## Solucao de problemas
- Se o texto nao atualizar, faca refresh forcado no navegador.
- Se falhar ao iniciar, execute `npm start` e verifique o terminal.
