# FLD-SyncBoard (Francais)

## Apercu
FLD-SyncBoard est une application web Node.js pour les donnees de base, modeles d'equipe, plannings et simulation API.

## Demarrage
```bash
npm install
npm start
```
Ouvrir: http://localhost:3000

## Fonctionnalites
- Changement de langue en direct
- Commutateur theme sombre/clair
- Integration SQL Server et MQTT
- Flux import/export et affectations

## Depannage
- Si les textes ne changent pas, faites un rechargement force.
- Si le demarrage echoue, lancez `npm start` et verifiez le terminal.
