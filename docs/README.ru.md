# FLD-SyncBoard (Russian)

## Обзор
FLD-SyncBoard — это Node.js веб-приложение для мастер-данных, моделей смен, расписаний и API-симуляции.

## Запуск
```bash
npm install
npm start
```
Открыть: http://localhost:3000

## Возможности
- Переключение языка во время работы
- Переключение темной/светлой темы
- Интеграция с SQL Server и MQTT
- Импорт/экспорт и сценарии назначений

## Устранение проблем
- Если текст не меняется, сделайте жесткую перезагрузку браузера.
- Если запуск не удался, выполните `npm start` и проверьте ошибки в терминале.
