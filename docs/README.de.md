# FLD-SyncBoard (Deutsch)

## Ubersicht
FLD-SyncBoard ist eine Node.js-Webanwendung fur Stammdaten, Schichtmodelle, Schichtplane und API-Simulation.

## Start
```bash
npm install
npm start
```
Offnen: http://localhost:3000

## Funktionen
- Sprachwechsel zur Laufzeit
- Dunkel-/Hell-Design Umschalter
- SQL-Server- und MQTT-Integration
- Import/Export und Zuordnungsablaufe

## Fehlerbehebung
- Wenn UI-Texte nicht aktualisiert werden: Browser hart neu laden.
- Wenn der Start fehlschlagt: `npm start` ausfuhren und Terminalfehler prufen.
