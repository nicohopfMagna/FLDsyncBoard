# FLD-SyncBoard (Korean)

## 개요
FLD-SyncBoard는 마스터 데이터, 교대 모델, 교대 일정, API 시뮬레이션을 위한 Node.js 웹 앱입니다.

## 시작
```bash
npm install
npm start
```
열기: http://localhost:3000

## 기능
- 런타임 언어 전환
- 다크/라이트 테마 전환
- SQL Server 및 MQTT 연동
- 가져오기/내보내기 및 할당 워크플로

## 문제 해결
- 텍스트가 바뀌지 않으면 브라우저를 강력 새로고침 하세요.
- 시작 실패 시 `npm start` 후 터미널 에러를 확인하세요.
