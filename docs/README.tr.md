# FLD-SyncBoard (Turkce)

## Genel bakis
FLD-SyncBoard, ana veri, vardiya modelleri, vardiya planlari ve API simulasyonu icin bir Node.js web uygulamasidir.

## Baslatma
```bash
npm install
npm start
```
Ac: http://localhost:3000

## Ozellikler
- Calisma zamaninda dil degistirme
- Koyu/acik tema degistirme
- SQL Server ve MQTT entegrasyonu
- Ice/disa aktarma ve atama akislari

## Sorun giderme
- Metinler degismiyorsa tarayiciyi zorla yenileyin.
- Baslatma hatasi varsa `npm start` calistirin ve terminali kontrol edin.
