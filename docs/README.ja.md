# FLD-SyncBoard (Japanese)

## 概要
FLD-SyncBoard は、マスターデータ、シフトモデル、シフトスケジュール、API シミュレーション向けの Node.js Web アプリです。

## 起動
```bash
npm install
npm start
```
開く: http://localhost:3000

## 機能
- 実行時の言語切り替え
- ダーク/ライトテーマ切り替え
- SQL Server と MQTT 連携
- インポート/エクスポートと割り当てフロー

## トラブルシューティング
- テキストが切り替わらない場合はブラウザをハードリロードしてください。
- 起動失敗時は `npm start` 実行後にターミナルエラーを確認してください。
